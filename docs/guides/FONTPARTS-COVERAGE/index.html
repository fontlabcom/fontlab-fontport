    FontParts yardstick and RoboFab mapping

    Regenerate the complete per-ID ledger with uv run python tools/fontparts-coverage.py --reuse-parity. Omit --reuse-parity to re-run host-free parity. Supply --native-evidence with the round14 directory when outside the workspace; the default searches ancestors.

    Host-free parity uses FontParts 1.1.1, which exposes fontParts.test.testEnvironment (singular test), with 1,797 IDs. Real upstream fontshell: 1,796 pass, one upstream skip (TestImage.test_bool_data_len_zero: “Cannot set zero data”). The live-font/UFO-backend run: 1,748 pass, 48 UnsupportedCapability, the same skip, zero unclassified failures. Pytest checks every ID and prevents new capability exclusions without updating the reviewed 48-ID baseline.

    These counts are not native passes. The per-ID fixtures column distinguishes real live RFont/UFOBackend objects from upstream's detached fontshell objects. The latter are parity checks, not FontGate fixtures. No package namespace is impersonated. Full raw tracebacks/fixture routes are retained in verification/issue-105/round10/{fontshell,memory}.jsonl.

    The native callable is fontlab_fontport.testing.object_generator(cls_name):

    The examples require installed fontlab-fly>=1.3.0 and their canonical providers.

    from fontParts.test import testEnvironment
from fly.fp.testing import ObjectGenerator, generator_context, object_generator

with generator_context(ObjectGenerator()):
    passed = testEnvironment(object_generator, inApp=True)

    Do not run that monolithic invocation through run_python. C4 uses round10.py instead: one upstream ID per RPC, followed by separate per-owner cleanup RPCs. Use --native-attached for the attached upstream column (default: orphan column). Each column is observed independently. The f3d7dc5 run separately counts the exact 72 C4-reviewed orphan/parent IDs as HarnessExclusion with capability testing.nativeAttached.parents in attached mode only. The reviewed ID list is in testing_exclusions.py; no assertion text is classified heuristically. All other assertions/bare NotImplementedError remain unclassified failures. The native driver first exercises ObjectGenerator(native_attached=True) for all 16 families. Every native document is created/owned, tracked before wrapper construction, and closed with close_font(save=False) on the finally path. Guideline/image creation returns explicit capability refusals.

    Upstream's ordinary object generator requires orphans with no parent. This adapter currently binds registered documents; detached native wrappers are not implemented. This is an adapter limit, not a claim that FontGate has no detached object API. Native orphan requests refuse as testing.nativeOrphan.<family>; attached fixtures must not be presented as passing those parent assertions. Selection is also explicitly unavailable. Native font tests exercise real registered documents. Native assertions and unexpected errors remain failures with tracebacks; the controller never calls them host defects merely because FontLab was involved. C4 must attach a minimal --test-id reproducer and an upstream fl issue to any confirmed host defect.

    C4's f3d7dc5 / FontLab 9.0.9783 native run classifies all 1,797 IDs in both modes: orphan 432 pass / 1,365 named capability / 0 unclassified; attached 1,087 pass / 638 named capability / 72 harness exclusions / 0 unclassified. These are C4 observations, not a host-free lane's native run. Source: workspace verification/issue-106/evidence/issue-105/round14/SUMMARY.md, upstream-out/20261016T043446540472Z-49425680/{receipts.jsonl,result.json} and upstream-attached-out/20261016T043701928259Z-14a1ddd8/{receipts.jsonl,result.json}. There are no separate round14 classification JSON files: the generator consumes the actual per-ID classifications in receipts and reconciles both result counts. It rejects missing/duplicate IDs, unnamed capabilities and unclassified results. Pass/capability/harness are separate outcomes; parent harness exclusions are not product failures or native passes. Row 30.1 closure remains controller-owned. The driver exits nonzero for any unclassified result, mismatch or slow phase. Its trace guard checks Python work; a blocking native call cannot be preempted. Any phase reaching four seconds needs a C4 ticket and further splitting.
