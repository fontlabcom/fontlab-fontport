    C4 re-run after Fontport T1–T13 repairs

    The input is C4's FontLab 9.0.9783 evidence at workspace verification/issue-106/evidence/issue-105/round10/TICKETS.md. Original receipts remain untouched. These repairs are host-free and need fresh native proof.

    Each command is a separate restarted, no-user-document session. The wrapper finds the workspace, supplies client dependencies and creates unique owned-copy outputs. No corpus or user font is written; owned documents close with close_font(save=False) in finally. Each native phase has a 3-second Python budget and a 4-second wall-time failure boundary, with polls between phases.

    T9 source evidence

    Read-only C++ root: <FontLab C++ source checkout> (FontLab Ltd. internal, read-only).

    • Font Info load/store uses weight_value/width_value and panose_string: Proteus/workspace2/fontinfo_data.cpp:391–402,586–596.
    • Their Python properties are bound at Proteus/pygate/pyflpackage.cpp:949,951, 1512–1516. Echopy fontlab.pyi declares weight_value, width_value and panose.
    • Master storage setters: Proteus/common/model/flpackage.cpp:17211–17220, 17350–17360. Master VFJ/history serialization writes the actual weight/width fields at :5853–5854 and Panose at :5875; reads at :4855–4860,4921–4925.
    • The old info setters write regenerated fg::Style data at Proteus/pygate/pyflpackage.cpp:2031–2078,2263–2287,2724–2758.
    • Real localized names are stored by Font Info via setLocalizedNames at fontinfo_data.cpp:520 and flpackage.cpp:16806–16836. That API has no Python binding in pyflpackage.cpp or echopy stubs. MCP's supported global write fields (Proteus/common/mcp/mcptools_fonts.cpp:469–565) omit localized/name records. Fontport therefore refuses changing name-record batches, including mixed batches, before history/data changes. It does not claim native support from the existence of the derived fg::Style setter.

    T1 resolves actual native references rather than creating placeholders: MCP's class creation requires glyphListFromNames before commAddKerningGroup (Proteus/common/mcp/mcptools_metrics_kerning.cpp:709–715).

    391 real upstream contour/segment/bPoint/point IDs also run host-free over a UFO backend that validates every forwarded contour using the actual FontGate point-pen adapter. This is geometry-contract coverage, not native Undo proof.
